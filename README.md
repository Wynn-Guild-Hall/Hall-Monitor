# Hall-Monitor

Discord bot for the Wynncraft Guild Hall — a cross-guild platform where representatives from major Wynncraft guilds can coordinate.

For more information, see **[hall.wynnvets.org](https://hall.wynnvets.org)**.

---

Currently hosted on infrastructure loaned by the Wynncraft Veterans guild; portability lives in `WYNNCRAFT_API_BASE`, `WYNNPOOL_API_BASE`, `MOJANG_API_BASE`, `PLAYERDB_API_BASE`, and the Discord role/channel IDs — swap those in `.env` to move hosts.
